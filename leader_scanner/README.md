# 주도주 스캐너 (거래대금 상위순)

KRX 데이터(pykrx)로 코스피·코스닥 거래대금 상위 종목을 가져와 3가지 정량 조건을 자동 검사합니다.

| 조건 | 기준 |
|---|---|
| ① 거래대금 | 당일 `--min-value`억 이상 (기본 500) |
| ② 상대강도 | 최근 `--days`일(기본 5) 수익률 > 해당 시장 지수 수익률 |
| ③ 탄력성 | 당일 고가 등락률 ≥ 10% 또는 최근 20일 내 (거래량 ≥ 직전 20일 평균×3 & 상승률 ≥ 10% 양봉) |

## 결과 보는 법
- **종목 목록:** 충족수 내림차순, 같으면 등락률 내림차순으로 정렬됩니다.
- **섹터/테마별 대장주:** `themes.json`의 테마를 우선 쓰고, 없는 종목은 KRX 업종으로 묶습니다. 그룹 안에서 거래대금 1위가 대장(★)입니다. 테마 종목은 `themes.json`을 열어 직접 추가·수정하세요. 대장은 스캔한 상위 종목(`--top`) 안에서만 정해지므로 `--top 50` 등으로 늘리면 더 정확합니다.
- **장대양봉 기준 자동 조정:** 3조건 충족 종목이 `--min-hits`(기본 3)보다 적으면 거래량 3배/10% → 2배/7% → 1.5배/5% 순으로 완화하고, 어떤 기준이 쓰였는지 화면에 표시합니다. 고정하려면 `--no-auto --vol-mult 3 --body-pct 10`.
- 단계별 통과 종목 수(②, ③, 3조건)도 같이 출력되어 어느 조건이 병목인지 알 수 있습니다.

## KRX 로그인 (필수)
최신 pykrx(1.2 이상)는 KRX 로그인이 필요합니다.
1. https://data.krx.co.kr 에서 무료 회원가입 (이미 있으면 그 계정 사용)
2. 실행하면 아이디/비밀번호를 물어봅니다 (비밀번호는 저장되지 않음). 매번 입력이 번거로우면 환경변수로 설정:
   - Windows(cmd): `set KRX_ID=아이디` / `set KRX_PW=비밀번호`
   - PowerShell: `$env:KRX_ID="아이디"; $env:KRX_PW="비밀번호"`

## 실행 (본인 PC)
```
pip install -r requirements.txt
python scan.py                      # 날짜를 물어봄 (엔터 = 오늘). 3조건 모두 충족 종목 출력
python scan.py --date 2026-10-14    # 그날 데이터 기준으로 분석 (휴장일이면 직전 거래일)
python scan.py --all                # 거래대금 상위 전체와 조건별 충족 여부
python scan.py --min-value 1000 --days 3 --top 50
```
`당일유형` 열: 지수 하락일에 오른/덜 빠진 종목은 "방어", 지수 상승일에 10% 이상 오른 종목은 "탄력".
결과는 `leaders_YYYYMMDD.csv`로도 저장됩니다(엑셀에서 열 수 있음).

## 주의
- 장 마감 후(오후 4시 이후) 실행하세요. 장중에는 당일 데이터가 비어 있을 수 있습니다.
- 섹터/테마 분류(대장주 판단)는 포함하지 않았습니다. 상위 종목을 보고 직접 묶어서 보세요.
- pykrx는 KRX 사이트 변경에 영향을 받습니다. 오류가 나면 `pip install -U pykrx` 후 재시도하세요.
- 투자 판단과 손익의 책임은 본인에게 있습니다.
